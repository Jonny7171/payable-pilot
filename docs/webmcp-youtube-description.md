# YouTube title

PayablePilot WebMCP demo: human-gated invoice review

# YouTube description

PayablePilot gives a browser agent structured access to an accounts-payable
exception without giving it payment authority.

This demo shows `review_payables_queue` returning the exact source evidence for
a $200 invoice variance. It then shows `stage_invoice_resolution` placing a
credit-and-hold draft in the visible review panel. A person still has to confirm
or dismiss that draft.

Live demo: https://jonny7171.github.io/payable-pilot/

Source: https://github.com/Jonny7171/payable-pilot

The invoice records and packet IDs in the demo are fictional.
